## Working rules

1. **Always dry-run first:** `kubectl apply --dry-run=server -f <file>` (or `helm ... --dry-run`).
2. **Check what will change:** `kubectl diff -f <file>`; on 2026-10-06 every file here showed *no difference* from the live
   cluster, except `30-envoyproxy.yaml` (it leaves out a temporary node preference the live object still has).
3. **Read the status after applying** (`kubectl get <kind> -o yaml`, `status.conditions`): "applied" does not mean "accepted".
4. **Do not hand-edit `51-...`**: it is generated by `scripts/gen_linkerd_dashboards.py`.
5. Values you must change for another environment: the ACM certificate ARN (`30`), hostnames and the CORS origin list (`32`, `35`),
   the allowed IP addresses (`37`), namespaces in the `ReferenceGrant` (`31`), the opaque ports (`11`).
6. Comments in these files that mention **Istio** are history (they say why a setting reproduces an old behaviour).
